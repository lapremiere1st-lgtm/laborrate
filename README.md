# 임률 산정 계산기 (9BXX 용접조립·프레스)

매월 ERP 급여자료(.xlsx)를 올리면 「연간임률산정」 엑셀의 연간통합 시트와 같은 방식으로 임률(원/H)을 계산합니다.

## GitHub Pages 배포
1. GitHub에서 새 저장소를 만듭니다 (예: `imryul`).
2. `index.html`, `README.md`를 업로드합니다 (Add file → Upload files → Commit).
3. Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `(root)` → Save.
4. 1~2분 뒤 `https://<계정>.github.io/imryul/` 주소로 접속합니다.

## 주의
- 급여 엑셀은 **저장소에 절대 올리지 마세요.** 이 페이지는 브라우저 안에서만 파일을 읽고, 서버로 전송하지 않습니다.
- 브라우저에는 월×부서코드별 합계만 저장됩니다(사번·성명 없음). 다른 PC에서는 다시 올려야 합니다.
- 무료 계정의 GitHub Pages는 공개 주소입니다(코드만 공개, 자료는 공개되지 않음).

## 계산 기준 (원본 수식과 동일)
- 인원 = Σ(제 일수) ÷ 산정기간 총일수
- 항목별 1인당 월평균 = Σ금액 ÷ 인원 ÷ 개월수
- 귀성비 = 법정통상일급 × 30 × 80% ÷ 12 / 연차수당 = 연차일수(근속연수 기준표) × 법정통상일급 ÷ 12
- 4대보험 = 직접인건비 × (고용+건강+건강×장기요양+산재+국민연금), 퇴직충당 = 직접인건비 ÷ 12
- 투입시간 = 본(일) × 8 + 연장 + 휴근 + 휴연 / 임률 = 인건비 총합계 ÷ 총 투입시간
